# Hermes Telegram MCP

Локальный MCP-сервер для чтения Telegram и явно запрошенных действий от имени пользователя через Telethon.

## Возможности

- `unread_digest` — непрочитанные чаты, счётчики и короткие фрагменты.
- `find_chat` — поиск чата по имени или username.
- `recent_messages` — последние сообщения.
- `search_messages` — текстовый поиск в истории одного чата с диапазоном дат.
- `download_attachment` — загрузка вложения по ID сообщения.
- `send_message` — отправка текста с поддержкой ответа и защитой от дубля при неопределённой ошибке.
- `send_file` — отправка локального файла.
- `edit_message`, `delete_message` — изменение и удаление собственных сообщений.
- `send_temporary_message` — отправка с последующим удалением того же сообщения.
- `preview_telegram_chat` — предпросмотр публичного канала/группы или ссылки-поста без вступления.
- `join_telegram_chat` — вступление по публичной ссылке или приглашению; запросы на одобрение и истёкшие приглашения возвращаются отдельным статусом.

Сервер работает через stdio. Чтение не помечает чаты прочитанными. Передача содержимого переписки модели — отдельный риск; используйте только доверенную локальную конфигурацию Hermes.

## Требования и установка (Linux)

Python 3.10+ и API credentials Telegram (`api_id`, `api_hash`) с https://my.telegram.org.

```bash
git clone https://github.com/OWNER/hermes-telegram-mcp.git
cd hermes-telegram-mcp
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
```

Создайте `~/.hermes/.env` (права `chmod 600 ~/.hermes/.env`) и задайте:

```dotenv
TELEGRAM_API_ID=YOUR_API_ID
TELEGRAM_API_HASH=YOUR_API_HASH
```

Пример без секретов: `examples/.env.example`.

## Первый вход через QR

Запустите интерактивно в своём терминале (QR отображается ASCII-кодом):

```bash
python login.py
```

В Telegram: Настройки → Устройства → Подключить устройство, затем отсканируйте QR. Если включена 2FA, пароль запрашивается скрытым вводом в терминале. Не публикуйте QR или файлы сессии.

По умолчанию Telethon-сессия и индекс чатов лежат рядом с `server.py`: `user.session` и `.cache/dialog_index.json`. Сессия содержит авторизационные данные; не синхронизируйте и не отправляйте её. Для отключения доступа откройте Telegram → Настройки → Устройства, выберите соответствующую сессию и завершите её.

## Hermes

Добавьте в конфигурацию Hermes (`mcp_servers`):

```json
{
  "mcp_servers": {
    "telegram": {
      "command": "/ABSOLUTE/PATH/hermes-telegram-mcp/.venv/bin/python",
      "args": ["/ABSOLUTE/PATH/hermes-telegram-mcp/server.py"]
    }
  }
}
```

Замените `/ABSOLUTE/PATH` на локальный путь. Не добавляйте ключи и токены в конфигурацию: сервер читает `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` из `~/.hermes/.env`.

## Примеры запросов

- «Что нового в Telegram? Не включай каналы»
- «Найди чат по имени … и покажи последние 10 сообщений»
- «Найди в чате … сообщения про встречу за последнюю неделю»
- «Отправь в чат … текст …»
- «Удали моё сообщение с ID … в чате …»
- «Отправь … и удали через 10 секунд»

Операции отправки, редактирования, удаления и скачивания выполняются только при явном вызове инструмента. Проверяйте адресата и текст перед отправкой.

## Предпросмотр и вступление

Предпросмотр не вступает в сообщество и показывает название, тип, username и доступный статус участия. Вступление выполняется только по явному запросу: поддерживаются `@username`, публичные ссылки `t.me/name` и инвайты `t.me/+...` / `t.me/joinchat/...`. Если требуется одобрение администратора, инструмент сообщает `request_sent`; это не означает, что вступление уже одобрено. Истёкшее приглашение возвращает `invite_expired`, используйте актуальную ссылку.

Примеры запросов Hermes:

- «Покажи предпросмотр https://t.me/python_academy через preview_telegram_chat»
- «Вступи в https://t.me/python_academy через join_telegram_chat»

## Обновление существующей установки

Сделайте резервную копию `user.session` и не удаляйте её. В каталоге существующей установки выполните `git pull --ff-only`, затем обновите зависимости той же средой: `.venv/bin/python -m pip install -r requirements.txt` (или `venv/bin/python ...`). Перезапустите Hermes. Сессию повторно создавать или запускать `login.py` не нужно. Если установка не является git-клоном, скачайте свежие `server.py`, `tests/` и документацию в копию каталога, сохранив прежние `user.session` и `~/.hermes/.env`.

## Проверки

```bash
python -m unittest discover -s tests
python server.py
```

Убедитесь, что Hermes подключает MCP и обнаруживает инструменты. Интеграционные обращения требуют авторизованной сессии Telegram; в тестах сетевые записи должны быть замоканы.
